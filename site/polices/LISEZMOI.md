# Polices du site

Fichiers WOFF2 (jeu de caractères latin) servis par le site lui-même, pour
qu'aucune visite ne transmette l'adresse IP du visiteur à un service tiers.

| Fichier | Police | Licence |
|---|---|---|
| `syne.woff2` | Syne | SIL OFL 1.1 — `OFL-syne.txt` |
| `schibsted-grotesk.woff2`, `schibsted-grotesk-italique.woff2` | Schibsted Grotesk | SIL OFL 1.1 — `OFL-schibstedgrotesk.txt` |
| `bricolage-grotesque.woff2` | Bricolage Grotesque | SIL OFL 1.1 — `OFL-bricolagegrotesque.txt` |
| `public-sans.woff2` | Public Sans | SIL OFL 1.1 — `OFL-publicsans.txt` |

Les fichiers proviennent de la distribution Google Fonts (polices variables).
